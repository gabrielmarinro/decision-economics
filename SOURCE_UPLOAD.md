`app/index.html`

Source file:

`DEMO BUSINESS MODEL.html`

Do not change the application code during upload. The GitHub Pages workflow validates `app/index.html`, deploys it as the site root, and publishes:

https://gabrielmarinro.github.io/decision-economics/

The source application is intentionally kept as a single-file artifact for this migration; architectural refactoring can happen afterward without changing the live product.
