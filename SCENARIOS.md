# Scenarios

Scenario analysis changes assumptions and observes the resulting economic state.

The system supports saving and importing scenarios as JSON and recalculating the model from the selected state.

## Scenario dimensions

- Customer mix
- Fleet growth
- Pricing
- Sales cycle
- PoC / acquisition cost
- Google Cloud consumption
- Operating costs
- Variable events
- Margin assumptions

**Change the assumptions → recalculate the system → inspect the consequence.**
